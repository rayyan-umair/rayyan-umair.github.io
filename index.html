Flagship Project
REXDR
Real-time Extended Detection & Response

REXDR is a self-hosted detection and response platform built from the ground up. Eight engines watch a network from different angles - Windows events, network traffic, DNS, Active Directory, asset discovery, and vulnerability intelligence - and write everything into a shared entity model.

A correlation layer continuously asks one question: is more than one engine describing the same thing? When the answer is yes, the platform stops producing alerts and starts producing an investigation - one attack chain carrying every contributing detection, the MITRE techniques involved, and a written narrative. The response engine then matches it against a playbook and writes an immutable case file.

  • Windows Security log collection over WinRM with authentication and persistence detections
  • Packet capture and flow aggregation - scanning, beaconing, exfiltration
  • Passive DNS analysis - entropy, frequency, tunnelling and DGA indicators
  • Active Directory events, group membership diffing, domain computer inventory
  • Cross-engine correlation into attack chains with 5W+H narratives
  • Playbook-driven response with automated containment and hash-chained case files
  • Network scanning with OS fingerprinting and service inventory
  • Version-aware CVE matching against discovered services
